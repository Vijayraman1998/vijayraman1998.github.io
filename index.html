§04 · CASE STUDIES

Calls I made, and what the data said.

Four decisions from production work, written the way I write them up for a team: the context, the call, and the result.

01LATENCY

Make the voice agent faster without a pricier model

Context
Callers notice dead air. The obvious fix was a faster, costlier model.
Decision
Instrumented every stage separately. LLM first-token latency dominated, so I shipped end-to-end streaming where speech synthesis starts on the first completed sentence.
Result
Time from final transcript to first audio held under 500 ms. Same model, same cost.
02EVALUATION

Reverse my own proposal when the evaluation disagreed

Context
Team consensus, mine included, was that answer quality needed a larger model.
Decision
Built an evaluation framework that scores retrieval and generation separately on labeled sets from real traffic. Most failures were in retrieval, so we fixed retrieval instead.
Result
Answer faithfulness up 35% against the prior baseline at flat inference cost. The upgrade would have cost more and fixed less.
03PLATFORM

Turn a services bottleneck into a self-serve product

Context
Every new agent needed an engineer, so delivery, not demand, set the pace.
Decision
Specified and drove a self-serve builder so client teams configure agents, prompts and tools themselves.
Result
Time to value cut from about 2 weeks to hours, with engineering effort moved off repeat delivery and onto the platform.
04RELIABILITY

Isolate tenants so no one gets throttled

Context
Many tenant accounts shared one WhatsApp pipeline, with different message priorities.
Decision
Scaled a multi-tenant queue on RabbitMQ with P1/P2/P3 priority routing, tenant isolation and 50-thread concurrency.
Result
200+ tenant accounts, zero throttling over 60+ days, and 3x peak traffic absorbed at full SLA.
§05 · HOW I BUILD

A closed loop, with a human gate at the end.

The pipeline I designed to take an agent from a requirements document to production.

01

Requirements

A requirements document goes in: scope, tools, escalation rules, success metric.

02

Draft

An agent drafts the system prompt, tool contracts, service code and schema.

03

Test cases

It synthesizes its own test cases, edge cases included.

04

Simulate & score

LLM-driven conversation simulations, scored automatically.

05

Green suite

Failures route back to the draft stage until every case passes.
